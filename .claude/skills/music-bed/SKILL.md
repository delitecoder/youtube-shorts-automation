# Music beds for Shorts

## Research summary (Nov 2026 — re-check licences before use)
| Model (GitHub) | Licence | Commercial use | Notes |
|---|---|---|---|
| **ACE-Step 1.5** (github.com/ace-step/ACE-Step-1.5) | **MIT** | Yes | Recommended. Instrumentals + vocals; GPU recommended, CPU works but slowly; `acestep.cpp` (MIT, unofficial) runs on CPU |
| HeartMuLa (github.com/HeartMuLa/heartlib) | Apache-2.0 (per repo) | Yes (verify) | Newer, less proven |
| Stable Audio Open / 3 | Stability Community Licence | Only under US$1M revenue | Registration required |
| MusicGen (audiocraft) | Weights CC-BY-NC | **No** | Do not use for a monetised channel |
| YuE / LeVo | Mixed / restrictive | Check | Avoid unless licence fits |

## How the pipeline uses music
1. Default: `src/ytauto/production/sound.py::synth_music` — an original procedural bed (pad +
   arpeggio + soft pulse), seeded per video, no third-party rights, CPU in < 1 s.
2. If `runtime/library/music/manifest.json` lists tracks, one is picked per video (looped/trimmed,
   ducked under narration with a sidechain compressor, -14 LUFS final mix) and credited.

## Generate a library with ACE-Step 1.5 (once, on a GPU machine or a free GPU notebook)
Run outside the daily task — never inside the scheduled run (too slow on CPU, large downloads).
1. Follow the repo's INSTALL.md (Python 3.11–3.12). Generate **instrumental** tracks only, 60–90 s,
   with prompts such as:
   - "calm lo-fi electronic, soft synth pads, light percussion, 92 bpm, curious, no vocals"
   - "minimal ambient tech, warm plucks, gentle pulse, 96 bpm, optimistic, no vocals"
   - "upbeat future garage, airy chords, subtle bass, 100 bpm, focused, no vocals"
2. Listen to every track; discard anything that resembles a known song.
3. Write `manifest.json` next to the WAV/MP3 files:
   ```json
   {"assets": [{"file": "calm_lofi_01.wav", "category": "music",
                "source": "Generated by the channel owner with ACE-Step 1.5 (MIT)",
                "license": "MIT model licence; generated output owned by channel"}]}
   ```
4. Upload files + manifest to Drive `01_Inbox/References/Music`, then run
   `PYTHONPATH=src python -m ytauto sync-library`.
Entries without `source` and `license` are ignored by the pipeline.

## Sound effects (Earshot)
Download the free Earshot SFX pack (Paul Urmson, itch.io), read its License.txt, then run
`python scripts/import_sfx_pack.py --pack <dir> --out sfx_library --source "Earshot SFX (Paul Urmson)" --license-file <dir>/License.txt`
and upload `sfx_library/*` to Drive `01_Inbox/References/SFX`. Without a library, procedural SFX are used.
